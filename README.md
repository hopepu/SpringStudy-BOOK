# Spring Framework 학습

2024년 8월에 시작한 Spring 학습 저장소입니다. 의존성 주입(DI)과 Spring MVC 프로젝트 구조를 익혔습니다.

- `@Component`, `@Autowired`를 이용한 빈 등록과 의존성 주입 (`Chef`, `Restaurant`, `SampleHotel` 예제)
- Lombok(`@Data`, `@Setter`)으로 DTO 보일러플레이트 줄이기
- Spring MVC 기본 설정(`root-context.xml`, `servlet-context.xml`)과 JUnit 테스트

## 기술
Java, Spring Framework 5.3, Lombok, Maven, JUnit
